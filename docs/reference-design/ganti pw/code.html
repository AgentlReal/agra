Ubah Kata Sandi

Perbarui kata sandi akun belajarmu secara mandiri. Gunakan kombinasi yang kuat dan mudah kamu ingat agar akun belajarmu tetap aman dan terlindungi.

Masukkan kata sandi aktif untuk memverifikasi kepemilikan akun.

Kriteria Keamanan Sandi :
  • Minimal 6 karakter (maksimal 12 karakter)
  • Memuat huruf kapital (A–Z) dan huruf kecil (a–z)
  • Memuat minimal satu angka (0–9)
  • Memuat simbol atau karakter khusus (@, #, $, %, dll.)

Ketik ulang kata sandi baru persis sama.
